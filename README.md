# Writer YooJung 작가 포트폴리오 웹사이트

## 구성
- index.html: 홈(랜딩페이지)
- about.html: 자기소개
- works.html: 작품소개
- guestbook.html: 방명록
- style.css / script.js: 공통 스타일 및 기능
- assets/robot-hero.jpg: 랜딩페이지 로봇 이미지

## 수정할 곳
각 HTML 파일에서 `Writer YooJung`, 소개 문장, 작품 제목과 설명을 실제 정보로 바꾸세요.
방명록은 데모 기능으로, 작성 내용이 방문자 브라우저의 localStorage에 저장됩니다. 여러 방문자 간 공유하려면 별도 서버 또는 데이터베이스 연동이 필요합니다.

## GitHub Pages 배포
1. GitHub에서 새 Public 저장소를 만듭니다.
2. 이 폴더 안의 파일과 assets 폴더를 저장소 최상위에 업로드합니다.
3. 저장소 Settings → Pages → Deploy from a branch → main / root를 선택하고 저장합니다.
4. 잠시 후 표시되는 `https://계정명.github.io/저장소명/` 주소로 접속합니다.
